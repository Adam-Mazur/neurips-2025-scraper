# Equivalent institution names, used by `scraper.py top-affiliations`.
#
# Format: a canonical name at the start of a line, followed by indented variant
# names that should be counted as it. The canonical name is what gets printed.
# Matching ignores case, accents, punctuation, "&"/"and", a leading "The", and
# repeated comma-separated parts ("Kyoto University, Kyoto University"), so each
# variant only needs to be listed once in any of those spellings.
#
# Merge rules used here:
#   - typos, abbreviations, translations and renames are merged
#     (Beihang = Beijing University of Aeronautics and Astronautics, Facebook -> Meta)
#   - departments, schools, institutes and hospitals of a university are merged
#     into the university; a company's labs and divisions into the company
#   - "X, <other institution>" entries, where OpenReview appended an unrelated
#     institution (e.g. "Peking University, Tsinghua University"), go to X
#   - separate organizations and campuses in another city stay separate:
#     Google vs Google DeepMind, Alibaba vs Ant Group, ByteDance vs TikTok,
#     CUHK vs CUHK-Shenzhen, HKUST vs HKUST (Guangzhou), HIT vs HIT Shenzhen,
#     each Chinese Academy of Sciences institute vs CAS vs UCAS, each Max Planck
#     institute, Mila vs Université de Montréal
#   - generic names that fit many institutions ("Department of Computer Science",
#     "Seed", "Max-Planck Institute") are left alone
